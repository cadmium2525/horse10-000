# 10,000 HORSE RACE

10,000頭が同時に走る、コミカルなサバイバルレース。あなたは最後尾からスタートして、9,999頭を抜いて1位を目指します。倒れた馬の山はジャンプで跳び越えましょう。

**遊ぶ: https://cadmium2525.github.io/horse10-000/**（ブラウザですぐ遊べます。インストール不要）

3D表現（ローポリ・玩具風）も効果音もすべてコードで生成しており、画像・音源ファイルは使っていません。

## 操作

### PC

| 操作 | キー |
|---|---|
| 左右に動く | `A` / `D` または `←` / `→` |
| ジャンプ | `Space`（`↑` / `W` でも可） |
| ダッシュ | `Shift`（押している間） |
| ポーズ | `Esc` または `P` |
| 同じシードでやり直し | `R` |
| 決定（タイトル・リザルト） | `Enter` |

### スマホ（横持ち推奨）

- 画面左半分をドラッグ: 左右に動く（スティックが指の位置に現れます）
- 右下の「ジャンプ」「ダッシュ」ボタン: ジャンプ／ダッシュ（別ボタンなので、ダッシュしてもジャンプしません）
- 縦持ちでは「横にしてね」が表示されます（レース中は自動でポーズします）

## ルール

- 出走は10,000頭。あなたの順位は常にリアルタイムで表示されます。
- ゴールした時点の順位が結果です。制限時間（150秒）内にゴールできないと **TIME UP** になります。
- 1位でゴールすると **WIN!**。さらに **転倒0回** なら **PERFECT** です（1位でも転倒していれば WIN! 止まり）。
- 他の馬との接触や、倒れた馬への衝突で転倒することがあります。倒れた馬はジャンプで跳び越え、ダッシュは前が空いているときに。
- 結果はカード画像（横長 1200×630 / 縦長 1080×1350）になります。背景はゲームの3Dシーン（あなたの馬と1万頭の馬群）をゴール時に撮影したものです。
- 共有ボタンは「スコアを共有する」の1つだけです。
  - スマホなど画像ファイルの共有に対応した環境では、OS の共有シートが開き、画像・投稿文・URL がまとめて X / LINE / Instagram などに渡ります。
  - PC など非対応の環境では「共有先を選ぶ」シート（X / LINE / Facebook / 画像を保存）が開きます。SNS の投稿画面には画像を付けられないため、SNS を選ぶと画像を自動で保存します。投稿画面で添付してください。
  - 投稿文にはハッシュタグ `#10000HorseRace` `#10000頭競馬` とプレイURL（`?seed=` 付き）が入ります。

### シードの共有

コースと馬の動きは「シード」で決まります。URL に `?seed=12345` を付けると、誰でも同じコース・同じ馬群で挑戦できます（数値または任意の文字列）。リザルトの「もう一度（同じコース）」や共有URLにはシードが入っています。

### 記録について

記録（順位・タイム・自己ベスト）は **ユーザーの端末で生成・保存される自己申告** です。サーバーによる検証やランキングはありません。自己ベストと設定はブラウザの localStorage に保存されます。

## 開発者向け

### ローカル開発

Node.js 22 で動作確認しています。

```sh
npm ci          # 依存のインストール
npm run dev     # 開発サーバー（vite）
npm test        # テスト（vitest。フルで数分かかります）
npm run build   # 型チェック + 本番ビルド（dist/）
npm run preview # ビルド結果の確認（http://localhost:4173/horse10-000/）
```

### デバッグ用 URL パラメータ

`src/main.ts` で解釈されます。複数を `&` でつなげられます。

| パラメータ | 内容 |
|---|---|
| `?seed=12345` | レースのシード（数値または任意の文字列） |
| `?debug=1` | FPS / sim・描画の時間 / LOD などのオーバーレイを表示 |
| `?autoplay=1` | ボットがプレイヤーを操作（タイトルを省略） |
| `?pr=1` | ピクセル比を固定（自動画質を無効化） |
| `?q=0..3` | 初期の描画 LOD レベル（0 = 最低） |
| `?ff=20` | レース開始直後に 20 秒早送り（タイトルを省略。最大 300） |
| `?start=1` | タイトルを省略してすぐレース開始 |
| `?ogp=1` | OGP 画像を単体で描画（`scripts/gen-ogp.mjs` が使用） |

詳細は [docs/dev-notes.md](docs/dev-notes.md)、仕様は [docs/design.md](docs/design.md) を参照してください。

### GitHub Pages への公開

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. `main` に push すると `.github/workflows/deploy.yml` がテスト・ビルドを実行し、`dist/` を Pages にデプロイします（手動実行も可）。
3. 公開URLは `https://<ユーザー名>.github.io/horse10-000/`。`vite.config.ts` の `base` はリポジトリ名（`/horse10-000/`）に合わせてあります。

### 画像アセットの再生成

- `node scripts/gen-ogp.mjs`: `public/assets/ogp.png`（要 Playwright。事前に `npm run build && npx vite preview --port 4317`）
- `node scripts/gen-icon.mjs`: `public/apple-touch-icon.png`（`public/favicon.svg` から生成）
